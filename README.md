# Oficina do Sim

Loja virtual desenvolvida para a empresa Oficina do Sim.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS

## Funcionalidades

- Catálogo de produtos
- Carrinho
- Favoritos
- Quiz para noivas
- Calculadora de lembrancinhas
- Consultora IA
- Kits personalizados
